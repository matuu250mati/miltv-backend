# MILTV Backend

Production API bootstrap for MILTV.

## Endpoints
- `GET /health` — public health/version contract used by the production gate.
- `GET /` — service identity.

## Render
- Build command: `npm install`
- Start command: `npm start`
- Environment: `NODE_ENV=production`
- Environment: `MILTV_VERSION=5.42.0`
